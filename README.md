# Análisis de Datos y Detección de Patrones en la Liga Panameña de Fútbol (LPF)

## Descripción

Proyecto personal de análisis de datos deportivos desarrollado con Python, Excel y SQL Server, enfocado en la recopilación, organización y análisis de información histórica de la Liga Panameña de Fútbol (LPF).

El objetivo principal es construir una base de datos histórica que permita identificar tendencias, patrones repetitivos y posibles anomalías relacionadas con equipos, entrenadores, árbitros, jugadores y eventos de partido.

## Objetivos

* Analizar el rendimiento histórico de equipos de la LPF.
* Construir una base de datos estructurada con información deportiva relevante.
* Detectar patrones recurrentes mediante consultas SQL.
* Identificar comportamientos estadísticamente atípicos para su posterior análisis.
* Generar informes comparativos por temporada y análisis consolidados de múltiples campañas.

## Tecnologías Utilizadas

* Python
* Microsoft Excel
* SQL Server
* Git & GitHub

## Flujo del Proyecto

### 1. Análisis Inicial (Python)

Se utiliza un modelo predictivo simple para calcular:

* Favorito del encuentro.
* Goles esperados.
* Tendencia Over/Under 2.5 goles.
* Nivel de confianza del análisis.

Esta etapa funciona como un sistema de observación preliminar para identificar partidos que requieren un análisis más profundo.

### 2. Registro y Organización (Excel)

Los resultados obtenidos son almacenados y clasificados para:

* Seguimiento de partidos.
* Comparación de resultados reales.
* Registro de observaciones.
* Consolidación de estadísticas.

### 3. Validación y Cruce de Datos (SQL Server)

La información recopilada es cargada a una base de datos relacional para:

* Detectar patrones repetitivos.
* Analizar comportamiento de equipos.
* Evaluar impacto de entrenadores.
* Analizar participación de jugadores.
* Revisar tendencias relacionadas con árbitros.
* Investigar eventos como penales, tarjetas, faltas y tiros de esquina.

### 4. Informes Analíticos

Se generan informes por temporada con hallazgos relevantes, incluyendo:

* Rendimiento de equipos.
* Tendencias ofensivas y defensivas.
* Comportamientos recurrentes.
* Eventos estadísticamente inusuales.

### 5. Análisis Histórico

Una vez completadas varias temporadas, se realiza un análisis consolidado para comparar campañas y detectar patrones persistentes a lo largo del tiempo.

## Alcance

Este proyecto no busca reemplazar el análisis profesional ni generar predicciones definitivas sobre resultados deportivos.

Su propósito es desarrollar una metodología de análisis basada en datos que permita identificar tendencias, generar hipótesis y facilitar investigaciones estadísticas sobre el comportamiento de los distintos actores involucrados en la competición.
