# P.E.D.A.-Predicci-n-y-Exploraci-n-de-Datos-Deportivos
P.E.D.A. (Predicción y Exploración de Datos Deportivos) es un proyecto de análisis de datos aplicado a la LPF. Combina Python, Excel y SQL para evaluar rendimiento de equipos, identificar patrones, explorar tendencias y detectar eventos estadísticamente atípicos mediante el análisis histórico de múltiples temporadas.
